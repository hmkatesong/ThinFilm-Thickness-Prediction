# 설계: 반사율 스펙트럼 피처 엔지니어링 (CUAI Basic 3조, 윤서 브랜치)

2026-11-13 확정. 방법은 학부생 분석가가 흔히 쓰는 알려진 것으로 고른다 (발표에서 설명 가능해야 함).

## 질문
같은 모델과 같은 분할에서, 반사율 곡선을 가공한 피처가 원시 226개보다 두께 예측 오차(MAE)를 얼마나 줄이나. 왜 줄이나.

## 분할
- 주 분할 `skip`: train = 네 층 모두 10, 30, ..., 290 nm (50,625개). valid 20,000개와 test 100,000개 = 20, 40, ..., 280 nm가 한 층 이상 있고 300 nm가 없는 조합에서 서로 겹치지 않게 추출 (seed 0). 학습에 없던 두께를 맞혀야 한다.
- 대조 `random`: 전체에서 무작위 train 50,625개, valid 20,000개.
- test는 설정을 다 고른 뒤 한 번만 채점한다.

## 피처 그룹 (`src/features.py`)
raw 226 / sg: Savitzky-Golay 1차, 2차 미분 (창 11, 3차) / (아래 4종은 SG 평활 곡선에서 계산) fft: Hann 창 FFT 저주파 30개의 크기, 실수부, 허수부 / peak: find_peaks(prominence 0.03) 봉우리와 골 개수, 위치, 높이, 평균 간격 / band: 8구간 평균, 표준편차 + 전체 요약 / pca: 평활화 곡선 PCA 20개 (train으로 fit).

## 모델 (`src/models.py`)
mean, knn(k=1, 외우기 기준선), ridge(alpha 4개 중 valid로 선택), lgbm(층별, lr 0.05, 실제로는 E07부터 0.1이고 아래 '실제 진행과 다른 점' 참고, leaves 63, colsample 0.5, subsample 0.8, valid MAE early stopping), mlp(sklearn (256,256), early stopping).

## 순서
1. 기준선: mean, knn, ridge raw, lgbm raw (skip/valid) + lgbm raw (random/valid)
2. FE 누적: raw, +sg, +fft, +peak, +band, +pca 를 lgbm 시드 1개로. 효과 없는 그룹은 빼고 다음으로. 마지막에 FE만(raw 제외) 1회
3. 최종: lgbm raw vs 최선 FE, 시드 0,1,2
4. ridge, mlp 각각 raw vs 최선 FE
5. test 1회 채점 (최선 FE 모델과 knn), 오류 분석

## 멈추는 조건
- G1: valid에서 lgbm 최선 FE가 lgbm raw보다 MAE 20% 이상 낮음, 시드 3개 평균 차이가 표준편차보다 큼
- G2: 최종 모델 test MAE < knn test MAE
- G3: 기여도 표, experiment_log.csv, 결과 문서 완성
- 또는 실험 25개(로그 행 수, 시드 묶음 1개 = 1행)에 도달. 미달이면 미달인 채로 보고.

## 범위 밖
굴절률, 박막 광학 공식을 쓰는 피처(광학 두께 등), torch 신경망, 하이퍼파라미터 대규모 탐색. 결과 문서에 확장 가능성으로만 적는다.

## 실제 진행과 다른 점 (실행 후 추가, 2026-11-13)

위 계획은 실행 전 설계라 그대로 둔다. 실제로 달라진 점:

- 학습률: E04(0.05)가 5,000그루 상한에 닿아 E07부터 기본값 0.1로 바꿨다. 0.1도 상한에 닿았고 원시 MAE는 0.8 nm 나빴다(34.46에서 35.26). 이후 실험은 모두 0.1로 통일했다. E04, E05만 0.05다.
- FE 순서: 누적 대신 원시에 그룹 하나씩만 붙인 실험 5개(E08~E10, E12, E13)를 먼저 돌리고, 조합 3개(E14~E16)를 돌렸다. 누적 경로는 돌리지 않았다. SG는 효과가 있었지만 최종 조합에서 뺐다. 5종 전부(E15)보다 0.16 nm 나빠도 시간이 절반 이하라서다. 이 시간 기준은 설계에 없었다.
- 대조 추가: 무작위 분할 1-NN을 같은 크기(E06)와 8:1:1 크기(E11)로 돌렸다. 같은 크기에서는 무작위 분할 점수가 더 좋게 나오지 않아서(26.4 대 건너뛰기 26.2), 8:1:1의 10.7은 학습 크기 효과로 해석한다.
- 단계 4가 단계 3보다 먼저 돌았다(E17~E19 다음 E20, E21).
- test: 최종 모델을 valid 최선인 MLP + FE로 바꿨다. MLP + FE(E22), knn(E23), LightGBM + FE(E24)를 각각 한 번씩 채점했다. 시드 예측 평균은 계획에 없던 수치라 test에서 먼저 봤고, valid에서 같은 효과를 확인했다(E25).
- early stopping: eval_metric l1을 줘도 지표 목록이 [l1, l2]라서 l2 정체로도 멈출 수 있었다. 실행 후 `first_metric_only=True`로 고쳤다. 상한까지 간 층은 영향이 없다(상한 전에 멈춘 E15 layer_1, E16 layer_2와 layer_4만 다를 수 있다).

| 단계 | 실험 |
|---|---|
| 1 기준선 | E01 mean, E02 knn, E03 ridge, E04 lgbm(lr 0.05), E05 lgbm random(lr 0.05), E06 knn random |
| 학습률 변경 | E07 lgbm raw(lr 0.1) |
| 2 FE | E08 +fft, E09 +sg, E10 +peak, E12 +band, E13 +pca, E14 4종, E15 5종, E16 FE만 |
| 대조 추가 | E11 knn random 8:1:1 |
| 4 다른 모델 | E17 ridge FE, E18 mlp raw, E19 mlp FE |
| 3 시드 3개 | E20 lgbm raw, E21 lgbm FE |
| 5 test | E22 mlp FE(시드 3개), E23 knn, E24 lgbm FE, E25 valid 시드 평균 확인 |
| 사후 확인 | E26 lgbm raw test (재검토 뒤 G1을 test에서 확인, 25개 상한 밖) |
